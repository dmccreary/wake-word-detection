# Dashboards

Dashboards are the counterpart to the labs. A lab measures something on the
board and prints a number; a dashboard lets you look at the measurement it came
from and decide for yourself whether the number is telling the truth.

Each one reads real data recorded on the kit, and shares its analysis code with
the command-line tool that prints the same figures — so a table and the picture
beside it cannot drift apart.
